## 4. Boundary and trajectory contract

`B_0` 是 embedding output；`B_j` 是第 j 个 decoder layer 后的状态。width-4 inclusive
window `s:s+3` 对应 `B_s -> B_(s+4)`。starts=`0...L-4`；SHIFT support=`1...L-5`；
CONSENSUS support=`4...L-8`。已核对 L=36，因此分别为 `0...32`、`1...31`、`4...28`。
`15:18` 为 `B_15 -> B_19`。

每个 validation identity 只做一次 native no-loop forward，answer position 为 renderer
prompt 最后 non-padding token，loop insertion=0。对 `z_l=FinalNorm(h_l)` 记录：

1. `choice_entropy = -sum p_l log p_l`；
2. `kl_to_final = KL(p_l || p_L)`；
3. `hidden_l2_to_final = ||z_l-z_L||_2/sqrt(hidden_dim)`；
4. `hidden_cosine_to_final = cos(z_l,z_L)`；
5. `hidden_cosine_distance_to_final = 1-hidden_cosine_to_final`，必须派生，不重复采集。

`p_l` 是四个 exact choice-token LM-head logits 的 stable float64 softmax。所有通用 window
delta 都存 `exit-entry`；selector 派生 `E=H_entry-H_exit`、`K=D_exit-D_entry`。
只保存 identity/provenance、四选项概率和标量；不保存完整 logits/probabilities/hidden
tensors、gold/correctness。

## 5. Frozen selector

primary selector=`ENTROPY_KL_CONSENSUS_WIDTH4_V1`：

```text
E(s)=mean[H_s-H_(s+4)]
K(s)=mean[D_(s+4)-D_s]
O_H=E(s)-mean(E(s-1),E(s+1))
O_K=K(s)-mean(K(s-1),K(s+1))
F_H=E(s)-mean(E(s-4),E(s+4))
F_K=K(s)-mean(K(s-4),K(s+4))
```

score descending/start ascending。

seed=20260722，`random.Random/randrange`，联合索引流，SE ddof=1，q*(R-1)
线性 percentile CI。

frequency >=0.80 才 `SELECTED`。否则必须输出明确的 `ABSTAIN_NO_POINT_ELIGIBLE /
