## 4. Boundary 与逐层指标

`B_0` 是 embedding output；`B_j` 是第 j 个 decoder layer 后、FinalNorm 前的 raw
residual-stream hidden；`B_36` 必须通过 frozen final-norm pre-hook 捕获 raw input。
`outputs.hidden_states[-1]` 的 post-norm 状态不能冒充 raw `B_36`。

### 4.1 Selector 的唯一输入

令：

```text
z_l = FinalNorm(B_l)
p_l = softmax_float32(LMHead(z_l)) over full vocabulary
```

对每个 identity、每个 boundary：

```text
H_l = -sum_v p_l(v) log p_l(v)
D_l = KL(p_l || p_36)
```

数值合同：

- LM-head logits 在 stable `log_softmax` 前转 float32；
- `H_l,D_l` 必须 finite；
- `D_36 <= 1e-6`；
- 完整 logits、probability、log-probability 不得持久化；
- full-vocabulary `H` 不得命名为 Choice Entropy。

V2 selector 只允许读取逐样本 `H_l,D_l`、identity、category 与冻结 provenance。

### 4.2 Hidden geometry：诊断专用

对 float32 `z_l,z_36`：

```text
hidden_rms_l2_to_final(l) = ||z_l-z_36||_2 / sqrt(hidden_dim)
hidden_cosine_to_final(l) = dot(z_l,z_36)/(||z_l||_2 ||z_36||_2)
hidden_cosine_distance_to_final(l) = 1-hidden_cosine_to_final(l)
```

cosine distance 必须由 cosine 派生，不能作为独立 producer metric 重复采集或重复计票。
zero norm/non-finite 必须 fail closed，不允许 epsilon fallback。

对 raw FinalNorm 前 `B_l,B_(l+1)`：

```text
cos_raw = dot(float32(B_l),float32(B_l+1)) /
          (||float32(B_l)||_2 ||float32(B_l+1)||_2)
adjacent_angular_distance(l) = acos(clamp(cos_raw,-1,1))/pi
```

angular scalar 必须 finite 且位于 `[0,1]`；`acos` 使用 float64 scalar。不得用
`1-cosine` 替代，不得在 FinalNorm 后计算，不得先平均 cosine 再 `acos`。

Hidden RMS-L2、cosine、cosine distance 与 adjacent angular distance：

- 必须输出 boundary/transition trajectory、per-layer delta、window delta 与 bootstrap CI；
- 可以用于结果解释和后续 hypothesis generation；
- 不得进入 `NewEligible`、`RateStable`、`S_RATE`、ranking、tie、selection frequency
  或 panel membership。

### 5.2 V1 admission 完整继承


### 5.3 Absolute-rate ranking

对每个 identity：

```text
G_H,i(s,w) = (H_i,s - H_i,s+w)/w
G_K,i(s,w) = (D_i,s+w - D_i,s)/w
```

点估计是 12,032 identities 的 micro mean。只有 `G_H,G_K` finite 且严格大于 0 时：

```text
S_RATE = sqrt(G_H * G_K)
```

`ABSOLUTE_RATE` 表示 reference-free 的中心窗口自身 rate，不是取绝对值。不得改为 total
change、算术平均、调和平均、最小值、加权和，或混入 hidden metrics、`S_REL`、
`S_SHAPE`。

### 5.4 Bootstrap 与 RateStable

冻结：

```text
method=category-stratified joint bootstrap over all 12032 identities
replicates=2000
selector_seed=20260801
standard_deviation=ddof1
epsilon=1e-12
linear_quantile=q*(R-1)
```

同一 replicate index map 必须联合重算全部 boundaries、H/K、42 windows 和 4 widths。
对每个窗口内 H/K 两维：

```text
SE_m = sd(G_m^(b),ddof=1)
M_b = max_m((G_m(point)-G_m^(b))/max(SE_m,1e-12))
c95 = max(0,Q_0.95(M_b))
LCB_m = G_m(point)-c95*max(SE_m,1e-12)
RateStable = (LCB_H>0) AND (LCB_K>0)
```

这只在同一窗口的 H/K 两维内 simultaneous，不声称 across-all-windows simultaneous
coverage。

### 5.5 选择终态

```text
C_RATE={W: NewEligible(W) AND RateStable(W)}
```

只在固定 point `C_RATE` 内按 point `S_RATE` 降序。科学 tie 使用
`math.isclose(rel_tol=1e-12,abs_tol=1e-12)`；width/start 只能稳定展示，不能破除 tie。
固定 `C_RATE` 后，每个 bootstrap replicate 重算 rate score；rate 非正的候选不可胜，
无 winner/tie 仍计入 2,000 分母。point top exact-window frequency `>=0.80` 才发布。

合法终态：

```text
ABSTAIN_NO_RATE_STABLE_ELIGIBLE
ABSTAIN_NO_UNIQUE_TOP1
ABSTAIN_RATE_RANK_UNSTABLE
SELECTED_WINDOW
```

non-finite、population/hash mismatch、anchor mismatch、verifier mismatch 是 `BLOCK`，不能
伪装成科学 `ABSTAIN`。
